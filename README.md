# Projeto-Individual-SoundMind 🎶
Projeto individual Full Stack: HTML5, CSS3, JavaScript, Node.js, MySQL e Chart.js. Focado em visualização gráfica de dados.

SoundMind

Transformando ritmos em autodescoberta e bem-estar mental.

A SoundMind é uma plataforma interativa que une tecnologia e musica. O projeto veio com o intuito de conscientizar as pessoas sobre como seus hábitos de escuta e estilos musicais que impactam diretamente suas emoções.

Funcionalidades Principais
Página Home: Conteúdo informativo composto de benefícios da musica para o bem estar mental

Cadastro/Login: Sistema de cadastro e login de usuários.

Quiz Interativo: Questionário personalizado para autodescoberta sobre o gênero musical preferido.

Dashboard: Painel de Kpis mostrando os dados com base nas respostas escolhidas pelo usuário.

Tecnologias e Arquitetura

Front-end: HTML5, CSS3 e JavaScript

Back-end: Node.js 

Banco de Dados: Modelagem lógica e script no MySql
